# Kickstarter-Crowdfunding-Analysis

## 1. Kickstarter Crowdfunding Campaign Analysis

Kickstarter Crowdfunding Campaign Analysis is an end-to-end Business Intelligence project developed using Excel, SQL, Power BI, and Tableau to analyze crowdfunding campaign performance, funding behavior, project success trends, category performance, and geographical patterns.

The project transforms raw Kickstarter campaign data into interactive dashboards and actionable business insights to understand the factors influencing successful crowdfunding campaigns.

## 2. Description

The Kickstarter Crowdfunding Analysis project focuses on analyzing campaign performance and identifying key factors associated with project success.

The dashboard helps users evaluate funding goals, pledged amounts, backer engagement, campaign categories, countries, project status, and staff-pick performance through interactive visualizations and KPIs.

## 3. Tech Stack

The project was developed using the following tools and technologies:

📊 **Microsoft Excel** – Data cleaning, KPI calculation, and pivot analysis.

🗄️ **SQL / MySQL** – Data extraction, aggregation, filtering, and query analysis.

📂 **Power Query** – Data transformation and preparation.

🧠 **DAX** – Created calculated measures and KPIs for dashboard analysis.

📊 **Power BI** – Built interactive dashboards, KPI cards, charts, filters, and business reports.

📈 **Tableau** – Used for visual analytics and interactive reporting.

🔗 **Data Modeling** – Created a star schema connecting Project, Category, Location, Creator, and Calendar tables for efficient analysis and filtering. 

## 4. Data Source

## 5. Features 

### Business Problem

Many crowdfunding projects fail because of poor planning, unrealistic funding goals, and limited visibility.

This analysis identifies the factors that influence campaign success and provides insights into funding behavior, category performance, and backer engagement. 

### Goal of the Dashboard

The Kickstarter Analytics Dashboard aims to:

- Analyze crowdfunding campaign performance
- Identify successful project trends
- Analyze category and location performance
- Evaluate funding goals and pledged amounts
- Understand backer behavior
- Create KPI-based dashboards
- Generate actionable business insights

## 7. Key Business Insights

- Lower funding goals are associated with higher project success.
- Staff Pick campaigns attract more backers.
- Product Design is a leading category.
- Strong campaign marketing supports better funding performance.
- Backer engagement plays an important role in project success.
